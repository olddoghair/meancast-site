    How we tested

    Open-Meteo keeps an archive of what each weather model predicted. We rebuilt MeanCast's forecast for every day from that archive, the same way the app does it, and compared it with the National Weather Service's forecast from the same morning. Then we scored both against each place's official weather station.

    The places are 11 we picked (big cities and small towns in very different climates) and 28 airports drawn at random, one per state. MeanCast fine-tunes each model using nearby weather stations, so to keep the test honest we hid each place's own station and made it learn from a different one nearby.
